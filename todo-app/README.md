# 待办事项应用 (Todo List App)

一个功能完整的待办事项管理应用，支持本地存储（Local Storage），完全离线工作。

## ✨ 功能特性

### 核心功能
- ✅ **添加待办事项** - 支持设置优先级
- ✅ **编辑待办事项** - 详细编辑标题、描述、优先级、截止日期、分类
- ✅ **删除待办事项** - 单个删除或批量清除已完成项
- ✅ **标记完成** - 快速勾选完成状态
- ✅ **本地存储** - 使用 LocalStorage 永久保存数据

### 高级功能
- 🔍 **搜索功能** - 按标题、描述、分类搜索
- 🎯 **优先级管理** - 高/中/低三个优先级
- 📅 **截止日期** - 设置任务截止日期，自动提示逾期
- 🏷️ **分类标签** - 为任务添加分类标签
- 📊 **实时统计** - 显示总任务、已完成、进行中、紧急任务数
- 🎨 **双视图模式** - 列表视图和网格视图切换
- 🔄 **智能排序** - 按时间、优先级、名称排序
- 🎭 **过滤器** - 全部、进行中、已完成三种过滤
- 📱 **响应式设计** - 完美适配各种屏幕尺寸

## 🛠️ 技术栈

- **前端框架** - React 18.2.0

## 📋 使用指南

### 添加待办事项
1. 在输入框中输入任务标题
2. 选择优先级（低/中/高）
3. 点击"添加"按钮

### 编辑待办事项
1. 点击任务右侧的编辑图标
2. 在模态框中修改信息
3. 点击"保存"提交修改

可编辑的字段：
- 标题 (必填)
- 描述 (可选)
- 优先级 (低/中/高)
- 截止日期 (可选)
- 分类 (可选)

### 完成任务
- 点击任务前的复选框标记为完成
- 已完成的任务会变暗并显示删除线

### 搜索和过滤
- **搜索框** - 按标题、描述、分类搜索
- **过滤按钮** - 全部、进行中、已完成
- **排序菜单** - 按时间、优先级、名称排序

### 视图模式
- **列表视图** - 详细的列表显示（默认）
- **网格视图** - 卡片式网格显示

### 删除任务
- 点击任务右侧的删除图标
- 确认删除

### 批量清除已完成
- 点击"清除已完成"按钮
- 会删除所有已完成的任务

## 💾 本地存储详解

### 数据结构

每个待办事项对象包含：
```javascript
{
  id: "时间戳字符串",           // 唯一标识
  title: "任务标题",            // 必填
  description: "任务描述",       // 可选
  priority: "high|medium|low",  // 优先级
  category: "分类",             // 可选
  dueDate: "2026-06-15",        // 截止日期（可选）
  completed: false,             // 完成状态
  createdAt: "ISO时间字符串"    // 创建时间
}
```

### LocalStorage 管理

应用使用 `todoStorage.js` 工具类管理所有存储操作：

```javascript
// 获取所有待办事项
todoStorage.getAllTodos()

// 添加新待办事项
todoStorage.addTodo({ title: "...", priority: "..." })

// 更新待办事项
todoStorage.updateTodo(id, { completed: true })

// 删除待办事项
todoStorage.deleteTodo(id)

// 清除所有已完成项
todoStorage.clearCompleted()

// 导出为 JSON
todoStorage.exportTodos()

// 导入 JSON
todoStorage.importTodos(jsonString)
```

### 浏览器存储

- **存储大小** - 通常 5-10MB
- **持久化** - 数据在浏览器关闭后仍然保存
- **安全性** - 仅在同一域名下访问

## 🐛 常见问题

**Q: 数据存储在哪里？**
A: 所有数据都存储在浏览器的 LocalStorage 中，不需要服务器。

**Q: 如何清空所有数据？**
A: 在开发者工具中删除 localStorage 或使用"清除已完成"功能逐步删除。

**Q: 可以在多个浏览器中同步吗？**
A: 不行，LocalStorage 是单浏览器存储。如需同步，需要服务器后端支持。

**Q: 数据会永久保存吗？**
A: 除非清空浏览器缓存或手动删除 localStorage，否则数据会一直保留。
